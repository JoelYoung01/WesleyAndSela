# Wesley & Sela

Wedding website. Static Vite + React + shadcn, hosted on GitHub Pages.

```bash
pnpm install
pnpm dev
```

Pushes to `main` build and deploy via `.github/workflows/deploy.yml`.

Pushes to `main` deploy to GitHub Pages. The github.io URL is:

https://joelyoung01.github.io/WesleyAndSela/

Custom domain (once DNS is in Cloudflare): `https://wesley-and-sela.joelyoung.dev`
